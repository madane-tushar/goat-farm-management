# GoatFarm Pro 🐐

A simple React UI for Goat Farm Management. No backend, no database — all mock data.

## Pages
- `/login` — Login & Register
- `/dashboard` — Stats, charts, recent goats
- `/goats` — Add, edit, delete goats
- `/finance` — Income & expense tracking
- `/vaccinations` — Vaccination tracker
- `/settings` — Profile & notification settings

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the app
npm start
```

App runs at: http://localhost:3000

## Notes
- Click Login with any email/password to enter
- All data is stored in React state (resets on refresh)
- No backend or database needed




## Features
- Goat records (add, edit, delete)
- Groups and hitting cycle tracking
- Breeding and pregnancy management
- Vaccination schedule
- Finance: income, expenses, net profit
- Dashboard with monthly charts and breed distribution

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MySQL

## Setup
1. Clone: `git clone https://github.com/madane-tushar/goat-farm-management.git`
